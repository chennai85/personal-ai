# My Vault

What my personal AI knows about me, so its understanding (buddhi) becomes *mine*.
The discernment (viveka) stays with me. BuWe.

## Rules of the vault

1. **It lives on the Mac Studio only.** Never in GitHub, never pasted into a cloud chat.
2. **Plain text.** I can read every file without special software.
3. **I write `me/`, `people/` and `rules/`.** The AI reads them. It never edits them.
4. **The AI writes `briefs/`.** I can delete any of it.
5. **`decisions/log.md` is mine.** What I decided and why, so next time it knows.
6. **Blank fields are fine.** `⟪ ⟫` means "not filled in yet". The AI skips them and says what it couldn't check.
7. **To forget something:** delete the line. To forget everything: delete the folder.

## Folders

| Folder | What goes in it | Who writes |
|---|---|---|
| `me/` | Facts about me: profile, money, travel, golf | Me |
| `people/` | The people in my life, one file each | Me |
| `rules/` | What to always check, what never to do | Me |
| `decisions/` | What I decided and why | Me |
| `inbox/` | Documents to read (proposals, bills, contracts) | Me |
| `briefs/` | What the AI understood, one file per document | The AI |

## How the AI uses it

```
document in inbox/  +  the vault files that matter for it  ->  brief in briefs/
     (what it says)        (what matters to me)                  (what I need to decide)
```

`index.yaml` says which files to load for which kind of document.
